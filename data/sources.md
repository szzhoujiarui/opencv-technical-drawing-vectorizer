# Fixture Data Sources

## Synthetic Fixtures

All synthetic fixtures in `data/fixtures/synthetic/` are programmatically generated by
`src/tdv/fixtures/synth.py`. The ground-truth primitives (line coordinates, circle
centers and radii, arc parameters) are recorded as JSON at generation time and are
deterministic (seeded RNG).

- **License:** MIT (self-generated)
- **Generator script:** `src/tdv/fixtures/synth.py`
- **Generation command:** `uv run tdv-make-fixtures -o data/fixtures/synthetic`

## Real Fixtures

No real fixtures are included in this release. Planned for Phase 4:
sourcing explicitly-licensed CC0 technical drawings from public archives.

If you have a permissively-licensed technical drawing (CC0, public domain,
or with a clear reuse license), please open an issue or pull request.
